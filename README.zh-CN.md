# 中文摘要

本仓库收集 Nikon 单反固件「**Firmware A / Firmware B**」双镜像打包方式的证据，
目标是补上 **D200（2008）→ Expeed 3（约 2012–2013）** 这段空白。

已核实的两个锚点：

- **D200 v2.01（2008）**：没有容器、没有加密，是两个裸闪存镜像。
  A = 256 KiB，日立 H8S/2600 控制 MCU；B = 3.75 MiB，富士通 FR 主控应用。
  两者尾部都是大端 CRC-16/CCITT；A 还带 8 字节「固件戳」
  （版本 + 修订 + BCD 构建日期）。
- **Expeed 4/5（2013–2017）**：容器内 A 模块图像里直接写着
  `Firmware A Copyright Nikon Corp.`，8 字节戳（横幅 + 尾部各一份）、
  CRC-16/CCITT 参数与 D200 完全一致；B 模块仍是「裸镜像 + 2 字节 CRC」，
  与 D200 的 B 同构。

中间缺的 **Expeed 1/2/3**（D3/D300/D90/D3s/D7000/D5100/D3200/D4/D800/D600/
D5200/D7100…）正是容器、加密、`a<型号码>_<版本>` 命名和 A 镜像横幅这四件事
被引入的时期。具体要收哪些样本、每个样本记录什么，见
[`docs/e3-gap.md`](docs/e3-gap.md)。

## 用法

```bash
python tools/nikon_fw_scan.py 固件文件 [--md]
```

支持裸镜像、解密后的容器、带 0x20 前缀的明文容器；输出模块名、大小、
CRC 校验结果、CPU 家族特征、A 镜像横幅与两份时间戳。

## 约定

- 仓库**不含任何固件二进制**，也不含解密密钥；固件版权属 Nikon。
- CRC-16 只是完整性，不是来源认证；不要直接刷改过的镜像。
- 与本仓库无关的结论一律标注为推断，能复现的才写进证据表。
